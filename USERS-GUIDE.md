# Using the team toolshed

The team toolshed is a shelf of skills your colleagues share with each other. A skill is a set of instructions that teaches Claude to do one job the way your team does it. Nothing to install: if you can sign in to Claude, you already have them.

## Use it in three steps

1. Start a new chat in Claude. A chat that was already open does not see new skills.
2. Ask: **What's in our toolshed?**
3. Ask for a job in your own words, for example the phrase Claude showed beside a skill. Claude picks the right skill itself.

## Good to know

- **Not working?** Start a new chat and say: **Run the toolshed check**. It tells you if the toolshed has reached you.
- **New skill missing?** Skills appear in a new chat within a few minutes of being added. Still missing after that: tell whoever looks after the toolshed.
- **Never put a password, key or customer data in a skill.** Everyone in the team can read every skill.
- **Want to add one?** Ask whoever looks after the toolshed. Builders using Claude Code say: **Add my skill to the team toolshed**.

## Who looks after it

The people who set up the toolshed follow the setup page they were given. They are the ones to ask for anything above.

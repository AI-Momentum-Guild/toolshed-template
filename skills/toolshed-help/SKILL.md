# Toolshed help

Tell the person what the team's shared skills are, using only what is really there. Never list a skill from memory.

1. Find the skills. They are the folders next to this one, each holding a `SKILL.md`. Read the `name` and `description` at the top of each. If you cannot open those folders, use the skills from this toolshed that you can see in this chat.
2. Leave out `toolshed-help` and `toolshed-check`; they are the toolshed's own helpers.
3. Show one line per skill: its name, what it does in plain words, and a phrase they could say to use it (taken from its description).
4. If there are none, say: "No other shared skills yet. Skills your team adds will appear here in a new chat."
5. Finish with two short reminders:
   - Skills are used by asking in your own words; there is nothing to install or switch on.
   - A chat that is already open does not pick up new skills. Start a new chat after a skill is added.
6. If they say a skill is missing, suggest running "run the toolshed check", then asking whoever looks after the toolshed to check the last sync time.
